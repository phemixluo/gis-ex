# GIS 解题地图集

面向全国大学生 GIS 应用技能大赛备赛的本地复习站。它以题目中的“任务/题目”作为大路线，再按届次、场次和方法类型筛选；点击任务可查看其下小问的执行顺序、所在整题路线、关键工具、易错点和对应解析。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

构建生产文件：`npm.cmd run build`。

## 内容结构

- `题目/`：用户提供的原题 PDF，是题目摘要和任务拆解的依据。
- `解析链接.txt`：用户提供的按届次、场次排列的外部解析链接，已逐一映射到对应题目。
- `src/data/problems.js`：11 套题、任务及任务内小问步骤的可维护内容配置。新增题目只需补充同结构对象。
- `src/data/articleSources.js` 与 `src/data/parsedArticles.js`：将 `解析/` 文件夹中的 11 篇本地 HTML 按题目映射，并抽取为可按任务筛选的解析段落；详情页会保留方法分支、参数文字和示意图链接。
- 任务详情中的“方法一/方法二”用于保留解析中的多种做法；工具标签已按 ArcGIS 工具名归一化，组合方法拆成单个工具显示。
- `src/App.vue`：筛选、URL hash 定位和详情展示。

## 内容与资料说明

本站为学习辅助，提供的是复习思路而非官方标准答案；关键操作应结合题目数据与软件版本复核。每道题均保留原题文件名和外部延伸阅读链接。外部文章仅作链接引用，解析正文来自用户提供的本地 HTML，用于站内按小问聚合展示，不替代原作者文章。

若补充新的解析 HTML：将文件放入 `解析/`，在 `src/data/articleSources.js` 增加“题目 ID → 文件名”映射，并同步更新 `src/data/parsedArticles.js`，最后运行 `npm.cmd run build` 检查。
